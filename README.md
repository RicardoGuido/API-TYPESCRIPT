Comando utilizados para iniciar este projeto:
 
npm init -y
npm i express dotenv
npm i typescript ts-node nodemon @types/express @types/dotenv -D
nps tsc --init
 
arquivos criados no início do projeto:
.gitignore
.env
 
Pastas criadas no início do projeto:
dist
src
 
---
 
Para rodar um script criando no package.json usar o comando:
npm run SCRIPT
